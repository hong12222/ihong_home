## 🧪 实验室

主页内置三个可以亲手点的轻量模拟，保留作品最核心的手感：

1. **语学 App** — 抖音式刷题：五道初中题、即时判定、答案解析、连击与命中统计
2. **小智 App** — AI 可选的手机助手：可关闭 AI 进入离线模式，模拟对话不发起真实网络请求
3. **丧尸危机** — 回合制生存：剧情 / 生存两种模式，射击、精准射击、治疗与换弹

> 均为基于公开信息的交互模拟，并非真实应用或游戏的完整版本 · 不收集数据、不发送网络请求
